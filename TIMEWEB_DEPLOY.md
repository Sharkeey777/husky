# Загрузка сайта на Timeweb

Сайт статический: ему не нужны PHP, база данных или сборка на сервере.

## Когда домен уже подключён

1. В панели Timeweb добавьте домен к сайту и дождитесь, пока для него будет выпущен SSL-сертификат.
2. В папке проекта выполните команду, подставив настоящий адрес:

   ```powershell
   npm run prepare:domain -- https://ваш-домен.ru
   ```

   Команда создаст папку `deploy`. В ней ссылки для поисковиков будут заменены на новый домен. Исходные файлы сайта и версия на GitHub не меняются.
3. Откройте файловый менеджер Timeweb и загрузите **содержимое** папки `deploy`, а не саму папку, в корневую папку сайта, которую показывает панель хостинга.
4. Откройте `https://ваш-домен.ru` в обычном окне браузера и проверьте:

   - меню и кнопку «Записаться»;
   - звонок, Telegram и соцсети;
   - Яндекс.Карты;
   - фотогалерею и просмотр фото;
   - страницу политики: `https://ваш-домен.ru/privacy.html`;
   - `https://ваш-домен.ru/robots.txt`;
   - `https://ваш-домен.ru/sitemap.xml`.

## Важно перед публикацией

- Кнопка MAX будет вести в личный чат только после того, как появится настоящая ссылка на профиль или чат в MAX. Сейчас ссылка по номеру телефона не работает со стороны MAX.
- После публикации можно прислать мне домен: я быстро проверю HTTPS, редиректы, заголовки и поисковые метаданные уже на настоящем адресе.
