# Лицензии локальных шрифтов

На сайте используются локальные файлы шрифтов **Onest**, **Unbounded** и **Caveat**.

Каждая гарнитура распространяется по лицензии [SIL Open Font License 1.1](https://openfontlicense.org/). Файлы получены из пакетов Fontsource версии 5.3.0 и хранятся в репозитории только для отображения сайта без внешнего подключения к Google Fonts.
